## Failures retained and corrected

The first full package failed its PHP upload case because the builder omitted authored `sql/schema.sql`. An independent unpacked-engine probe identified the missing data while Java/C#/Node ran successfully. The fixed manifest now requires that exact schema and all fixed per-engine resources; a negative source test proves omission is rejected before execution. No expected HTTP result was relaxed.

The next candidate completed all eight workflows but its acceptance harness looked for the licenses Text widget directly under a Toplevel, while the actual UI correctly nests it in a Frame. The harness now traverses the actual widget subtree and requires exactly one real license text with the expected runtime families. This was a harness selector defect, not evidence that notices were absent. The same original deadlines and checks remained in force. A developer CRT-discovery subprocess also required explicit built-in PowerShell module paths in the inherited environment; signature verification was preserved.

The first hosted native candidate at `b42e43c171bcb088647e1aff291f09440957b71e` built successfully but failed its real consumer at an opaque callback assertion; the other fourteen checks, including all four CodeQL categories and their aggregate, passed. The identical clean local candidate passed, so those facts alone do not identify the hosted cause. The consumer now retains and prints only bounded authored function/line/stage, counts and fixed component error categories. It does not print raw status, inputs, exception bodies, profiles or environment. The original failure and original deadlines/oracles remain unchanged; a later exact-head run must establish the actual outcome.
